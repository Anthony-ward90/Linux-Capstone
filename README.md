# Linux Capstone Project
## Operating, Securing, and Recovering a Linux System

A hands-on capstone project demonstrating real-world Linux administration and security skills.

## What This Project Covers

- System orientation and filesystem structure
- User, group, and permission management
- Package management and service configuration
- Process management and monitoring
- Log analysis and troubleshooting
- Firewall configuration with UFW
- Backup and recovery using tar
- Failure simulation and system recovery

## Skills Demonstrated

- Configuring file permissions using chmod and chown
- Managing users and groups from the command line
- Configuring and managing nginx as a system service
- Reading and filtering system logs with journalctl and grep
- Hardening a system with UFW firewall rules
- Backing up and restoring critical data
- Diagnosing and recovering from service failures

## Environment

Ubuntu Linux — VMware Virtual Machine
